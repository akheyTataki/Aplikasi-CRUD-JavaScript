# CRUD Produk DummyJSON

## Deskripsi

Aplikasi CRUD (Create, Read, Update, Delete) sederhana menggunakan JavaScript dan API DummyJSON.

Fitur yang tersedia:

* Menampilkan daftar produk
* Menambahkan produk baru
* Mengubah data produk
* Menghapus produk

## Teknologi yang Digunakan

* HTML
* CSS
* JavaScript (Fetch API)
* DummyJSON API
